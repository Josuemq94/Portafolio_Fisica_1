Tema 8 : Ruedas de reacción: cómo un satélite se gira sin empujarse contra nada

Programa del curso: Módulo 3 — Leyes de conservación; momento angular, torque y equilibrio rotacional.

(a) Caso de uso en Ingeniería del Software

Sistema real: el simulador de dinámica y actitud NASA 42 modela naves y subsistemas de control; satélites como Hubble emplean ruedas de reacción para modificar su orientación sin expulsar propelente en cada maniobra. El software integra sensores, controladores y actuadores sujetos a límites de velocidad y torque.

Sobre un eje fijo, el momento angular es Lz = Iω. Para el sistema formado por el chasis y la rueda, el torque externo neto es cero, Στext = dL/dt = 0; por tanto, el momento angular se conserva: Li = Lf.

Ltotal,z = Isatωsat + Iruedaωrueda = constante;   τmotor = Iruedaαrueda

El motor ejerce fuerzas y torques internos entre la rueda y el chasis: cambia el momento angular de cada parte, pero no el momento total del sistema. El torque de reacción hace que el chasis gire en sentido opuesto.

Ventaja y costo de modelarlo: interpolar cuaterniones puede suavizar una orientación, pero no basta: ignora la inercia real del chasis (Isat) y no predice la respuesta a torques. Integrar τ = Iα en el software de vuelo permite controlar la orientación y lograr apuntamiento de alta precisión con inercia y límites reales. El costo computacional incluye integrar el estado y resolver acoplamientos giroscópicos tridimensionales, además de manejar ruido y estabilidad numérica.

Conexión: las variables angulares y el movimiento circular del Tema 3 son la base cinemática; aquí se añade el momento angular y el torque.

(b) Recurso de apoyo: diagrama vectorial propio

Modelo de un eje con Isat = 100 kg·m² e Irueda = 0,1 kg·m², iniciado con momento angular total cero. Las inercias son supuestos didácticos, no datos del Webb.

Saturación y desaturación

Al alcanzar el límite de velocidad angular ωmax, el controlador ya no permite acelerar la rueda en esa dirección: α = 0 y, en este modelo, τmotor = Iα = 0 para ese comando. La rueda queda saturada y no puede seguir almacenando momento angular; el software debe activar propulsores para aplicar un torque externo real τext y desaturarla (los magnetorquers solo sirven si hay un campo magnético utilizable).

Fuentes técnicas: NASA 42 (simulador de dinámica de naves); NASA Small Spacecraft Systems Virtual Institute, Guidance, Navigation, and Control (ruedas de reacción, torquers magnéticos y propulsores). El diagrama es una elaboración propia de un modelo de un solo eje.
